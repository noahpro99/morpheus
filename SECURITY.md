# Security

## Reporting a problem

If you find a security problem in Morpheus, such as a way to read someone's
encrypted messages, take over a session or run code through a message, please
report it privately. Don't open a public issue.

Email **support@morpheuschat.org** with "Security" in the subject. Include what
you found, how to reproduce it, and the version and platform you tested. You'll
get a reply within a week. Please give us a reasonable time to fix the problem
before you publish anything about it.

## Supported versions

Morpheus is in early alpha. Only the latest release gets security fixes, so
please check that a problem still happens there before reporting it.

## Scope

This covers the Morpheus app (this repository), the website at
morpheuschat.org and the web app at app.morpheuschat.org. Problems in
matrix-rust-sdk, in a homeserver or in Matrix itself belong with those projects
(see the [Matrix.org security disclosure policy](https://matrix.org/security-disclosure-policy/)),
though we're glad to hear about them too.
