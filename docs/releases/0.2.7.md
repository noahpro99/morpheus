# Morpheus 0.2.7

Desktop only: Linux, Windows and macOS (Apple silicon and Intel). The phone apps are paused until they are rebuilt natively; the last ones are in 0.2.2.

## Calls and video
- Choose whether to watch a screen share: an unwatched share shows a greyed still frame and you click anywhere on the card to watch it. Nothing is sent while nobody watches.
- Right-click a call card to Hide video, which saves bandwidth. The sharer's own preview pauses while Morpheus isn't focused.
- A voice channel shows how long the call has been going (in the channel list, with digits that don't jiggle), and hovering a voice channel there shows a button that opens its chat.
- Focus layout: the focused card is as big as it can be, and it is centred together with the strip. The focused member keeps a greyed card in the strip, and a focused screen share's strip card shows its screen icon.
- Screen share cards carry a screen icon in their label. Clicking a card focuses it, and clicking the focused one unfocuses it.
- Windows: video decoding uses the graphics card on NVIDIA, memory is released after leaving a call, and the taskbar pin survives updates thanks to a stable launcher.
- The nix package is built with hardware video (VAAPI, NVENC/NVDEC) and finds your system's graphics drivers.
- The small noise suppression menu has a button that opens the full settings, and the microphone menu in the user area no longer shows noise suppression settings.

## Messages and chat
- Edit a message in place: the edit box replaces the message in the timeline.
- Spell check in the message box, with a red squiggle and right-click suggestions.
- Home and End keys work, and Page Down reaches the bottom.
- Ctrl+V pastes into the message box when nothing else has focus.
- The text caret no longer changes width while typing.
- Pinned messages: a newly pinned message shows up, and an unavailable pin no longer shows your name as its sender.
- The voice channel chat loads and caches its messages properly.
- Link previews: the whole card opens the link.
- Friends, nicknames and notes are encrypted by default, with no button to turn it on.

## Servers and channels
- Channel permissions: choose who can send messages (and related things) in a channel.
- The server overview has the member list on the side like a channel view, scrolls to the top and bottom on servers with many channels, and can collapse channel descriptions.
- Joining a server from an invite opens the server's own timeline.
- Discover is one full-page view across several directories, with Back going back and the user bar kept in place.
- The Create a server window has a Join a server button.
- Friends is one page, with Start a new DM at the top and the friends list below.

## Command palette
- Actions such as Create server and Discover, Close to background, Quit Morpheus and Restart.
- Start a DM opens the New message page, and there is a Join by address action.
- Restart works properly on Windows: the new copy is the version installed now.

## Getting around
- Every window has a close X at the top right, with the tooltip "Close (Esc)".
- The mouse back button closes popups like Escape does, and no longer closes Settings by accident.
- The inbox button toggles the inbox.
- The Hide members button has a people icon after the arrow, and a tooltip.
- Locked chats: set your own auto-lock time.

## Look and feel
- Tooltips appear below the pointer with an arrow that always points at the button, a better font and styled shortcut keys. Server rail tooltips go beside the icon, and tooltips hide when the button is clicked.
- Right-click menus highlight a row across the full width, only after the pointer has really moved onto it, and the microphone menu opens without delay.
- Streamer mode no longer turns on by itself by default, and icon buttons have tooltips.
- The photo viewer no longer shows a left arrow when there is no previous picture.

## Help and updates
- Patch notes are in Help & Feedback and show in a popup after an update.
- Debug info in Help & Feedback is collapsed by default.
- On Linux, the matrix: link registration no longer writes a broken launcher entry for dev builds and the nix package.
